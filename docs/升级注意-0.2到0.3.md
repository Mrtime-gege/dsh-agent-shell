# 从 0.2.x 升级到 0.3.x：语义变化与迁移须知

> 面向已经在用 0.2.x、准备升 0.3.x（当前最新 0.3.2 开发中）的你。功能清单见
> [CHANGELOG](CHANGELOG.md)，这里只写**行为变了、可能咬人**的地方。

## 1. 闲置自动关闭：默认反转为「永久保留」

0.2.3 的默认是"60 分钟闲置自动关"；0.3.0 起默认**永不自动关**：

- `shell_open` 不传 `idleMinutes`（或传 `0` / `-1`）→ 该会话永不被回收；
- 想启用：`shell_open idleMinutes=30`（正数分钟）或打开全局设置 `idleClose`（默认关，
  开动后只给"没给过显式时长"的会话兜底 `idleCloseMinutes`）；
- **老会话的既有值仍然生效**：0.2.x 时代开的会话带着当时写入的 `idleMinutes` 数字，
  升级后依旧按那个数回收。想让它永久：`shell_manage action=idle session=… minutes=-1`。

## 2. vault（`{{v:}}` 秘密域）：三条新规则

0.3.1 安全返工后的现行语义（0.3.0 的旧行为已被修复，别拿旧印象用新功能）：

1. **AI 只能"整条裸引用"**：`send:"{{v:键}}"` 单独一条喂给密码提示（`sudo -S`、`read -s`）。
   `echo {{v:键}}`、管道、夹心形态一律 REFUSED —— 实测证明值进了 AI 可加工的管线就能被
   变换还原（`| base64` 绕过一切显示侧遮蔽），这条规则把该路径从输入侧关死。
   人从面板输入不受限；宏闭环（`{{m:堡垒机}}` 内部嵌 `{{v:}}`）照常可用，宏文本全量入封链。
2. **oneShot 落刀在"送出那一刻"**（护栏通过后、进管道前），不再等"发送成功"；护栏**拒绝**
   的命令不烧键；同一条发送引用两次直接整条拒绝。
3. **打码是"行身份"不是全局替换**：只遮注入所在的行；无关文本里的同串字不遮（全局替换
   可被逐字符试探猜密）。因此**值的哈希、程序自己打印的值**不在保护能力内 —— 见 SECURITY §10。

另外 `submit:false` 的宏**不能再嵌 `{{v:}}`**（值不许悬在未提交的行上等拼接）。

## 3. 审计链：规范化与序列化同口径（无需迁移动作）

0.3.1 修复"带 undefined 字段的记录会让链从该条起全断"的潜伏 bug（规范化丢弃 undefined 键，
与 JSON 落盘一致）。旧记录本就没有 undefined 字段，链向后兼容，**不需要重封或清库**。
新增两笔可见变化：close 记录带 `transcriptSha256/transcriptBytes`（留痕见证，删改留痕可证）；
`vault` 事件多一种 `decision:expire`（键 TTL 自动焚毁）。

## 4. 工具与查询的小变化

- `shell_read` 新增 `mode=summary` / `mode=diff` / `ifChanged` / `search` 的 `context`、`offset`；
- `shell_run` 新增 `steps`（一次调用跑完交互序列）；
- 护栏拒绝消息带稳定错误码（`[code=guard:rm-root]`），按码分支别按文案猜；
- `shell_state` 每行带 `cwd=`，`withGit:true` 加 `git=分支`；released 的壳显示 `[已交还用户]`；
- 文档分工：英文 README 冻结于 0.3.1，一切以中文文档为准。

## 5. 升级操作本身

`npx -y dsh-agent-shell install`（或让 AI 跑）→ 重启 `dsh web`。面板资源随重启更新，
浏览器再刷新一次。数据目录不迁移、不清空；唯一的可见差异是上面 1–4 条行为。
